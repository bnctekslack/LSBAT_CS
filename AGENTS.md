## Build, Test, and Development Commands
- After modifying code, update `readme.txt` to reflect the behavioral or usage changes.
- After modifying code, update `version.txt` with the change summary/version history entry.

## Coding Style & Naming Conventions
- Indent 4 spaces; Allman braces consistent with existing code.
- Always add comments to newly added or modified code so the purpose of the change is clear.

## Review-Only Requests
- When the user asks to review, inspect, investigate, provide findings, reasoning, and recommendations only.
- Do not edit code, create patches, run formatters, or otherwise modify files for review-only requests unless the user explicitly asks to implement or fix something.
